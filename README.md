# Computer-Use Automation System

Record-once / replay-many automation for applications that expose no API.

An LLM drives a live application surface to accomplish a natural-language goal, the
successful run is frozen into a **typed, versioned capability artifact**, and that
artifact is thereafter **replayed deterministically with no model in the decision loop** —
with an explicit error taxonomy, safety guardrails, and a human-in-the-loop escalation path.

> Take-home project for the interface.ai engineering team.
